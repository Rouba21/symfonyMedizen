# symfonyMedizen — Symfony starter for MediZen

The initial Symfony 5.4 setup used to start the **MediZen** web project: framework configuration, Doctrine, Twig, Mailer, Stimulus and Turbo, with no business code yet.

> The full application (establishments, departments, users, admin, map, statistics) is in **[MediZen](https://github.com/Rouba21/MediZen)**.

## Tech

PHP · Symfony 5.4 · Doctrine ORM · Twig · Stimulus / Turbo · AssetMapper

## Run

```bash
git clone https://github.com/Rouba21/symfonyMedizen.git
cd symfonyMedizen
composer install
symfony serve        # or: php -S localhost:8000 -t public
```
